# Capitanes de tu Destino

Segunda vista de diseño para la comunidad de César Moreno, socio independiente de InCruises.

## Abrir y comprobar

Sin instalación de dependencias. Con Python 3: `python3 -m http.server 5173` desde esta carpeta y abrir `http://localhost:5173`.

Con Node: `npm run check` comprueba la sintaxis del JavaScript. No existe un build: HTML, CSS, JavaScript y SVG estáticos.

- `index.html`: viajeros, historia, membresías y comunidad.
- `emprende.html`: presentación independiente de negocio.
- `assets/styles.css`: sistema visual y responsive.
- `assets/app.js`: navegación, desglose de planes, modales y scroll.
- `assets/ship3d.js`: modelo geométrico 3D original, con WebGL y renderizado SVG de respaldo. Three.js fijado a 0.180.0 y distribuido con su licencia. La imagen de referencia de membresías es ilustrativa, no un testimonio.

## Estado y límites

Borrador, no oferta comercial publicada. Sin pagos, base de datos, captura de datos, chatbot conectado ni agenda. Los modales indican la ausencia de video/contacto en lugar de simular éxito. Los enlaces oficiales e Instagram sí son enlaces reales. No usar como página pública comercial antes de revisión.

El repo es público: NO subir contraseñas, contactos, documentos privados ni videos familiares sin la autorización correspondiente. Las fotografías y testimonios requieren autorización previa a publicación. Los viajes futuros se distinguen de experiencias realizadas.

La información inicial de membresías procede del contrato 106ES de abril de 2026; debe volver a verificarse antes de publicar. Los puntos no son efectivo ni inversión. La descripción Repayd se limita a valor neto pagado no utilizado ante insolvencia, sujeta a términos.
